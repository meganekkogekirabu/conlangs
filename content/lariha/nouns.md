Declension
==========

Nouns are declined according to their class:


Plain stem
----------

|            | singular | plural   |
| :--------- | :------- | :------- |
| nominative | -u       | (-)-wá   |
| accusative | -ca      | (u)-cá   |
| ergative   | (u)-áy   | (-)-áy   |
| inessive   | (u)-áru  | (-)-árun |
| locative   | (u)-ná   | (-)-nár  |


N-stem
------

|            | singular | plural    |
| :--------- | :------- | :-------- |
| nominative | -nu      | (-)-nᵚá   |
| accusative | -nca     | (u)-ncá   |
| ergative   | (u)-náy  | (-)-náy   |
| inessive   | (u)-náru | (-)-nárun |
| locative   | (u)-ená  | (-)-nnár  |
